# Installation

ForageBench runs inside the official IsaacLab 2.3 Docker container, which ships IsaacSim 5.1. Follow these steps in order:

1. [Set up the IsaacLab Docker container](01_isaaclab_docker.md)
2. [Install ForageBench inside the container](02_foragebench.md)
3. [Download the benchmark scenes](03_scenes.md)

Once installed, see [`eval/README.md`](../../eval/README.md) to run the benchmark.
